The explicit hqc-v3 benchmark target uses crucible.code_hqc_v3. The historical
hqc target still uses code_hqc_v2; its reports and identities are unchanged.
Native timing builds use a separate driver beneath .local/reference-native,
never overwrite challenge workers, and verify the frozen patched source inventory,
base library, parameter identity, adapter closure and resulting driver binary.

BuildInputs.hqc_model_root defaults to .local/native-hqc-model. The optional
--native-hqc-model-root command-line argument selects an existing reviewed input
tree; it is not an arbitrary plugin, library download or uploaded-code loader.
The report reader accepts the new target only for modeled-research-v3 and still
requires exact profile/source/parameter/artifact bindings and an operator-selected
publication digest. Adding a target never automatically publishes a report.
