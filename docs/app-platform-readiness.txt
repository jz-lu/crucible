Private access before launch

All routes, including static content and downloads, must pass the application.
Do not add an App Platform static-site component pointing at web/ or a public
object bucket/CDN. DNS and certificates identify the hostname publicly; only the
minimal login/bootstrap surface should be visible without admission.

Test anonymous visitors, authenticated nonmembers, members, revoked members,
reviewers and scoped agents. Include direct URLs, legacy routes, notebook exports,
protocol/method files, provider starter/preview domains and cached responses.
Only authorized exact revisions may be read; membership does not override private
draft ownership or review permissions. Restrict the provider domain to the same
boundary or reject it. A private source repository is not website access control.
