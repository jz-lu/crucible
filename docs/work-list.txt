Adapters — implemented and verified in the local candidate

- Finite-field Diffie–Hellman: teaching-dh-kem release 3, all integer sizes 20–128.
  n is subgroup-order bit length. Release 2 remains unchanged at 20–36; current
  boards/progress include v2 receipts only for that explicit compatible subset,
  keeping the original receipt source/version. Release 1's five profiles remain
  separately archived. Source hashes and earlier records are preserved.
- RSA over an integer modulus: rsa-kem release 1, all integer sizes 20–128.
  n is modulus bit length. Custom transcript-bound SHA-256 teaching construction;
  no claim of standardized RSA-KEM conformance.
- Both output 32-byte shared secrets. Exact registered arithmetic/encodings support
  perfect honest agreement; that is not a confidentiality/security certificate.
  Neither adapter is suitable for protecting information.
- Separate public-only DH/RSA demonstration solvers intentionally stop above size
  36 to bound naive algorithm costs. Larger challenges support participants' own
  methods. Solvers print candidate keys and never submit them automatically.
