INTRODUCTORY CHALLENGE

profile, regardless of the weekly choice or the community recovery frontier.

button alone does not issue an instance, spend allowance or submit anything.

silently substituting the weekly scheme. Owner, CSRF, document and route guards
retire delayed starts; only non-secret guide context is kept for reloads.
Guide phases use explicit local checkpoints: introduction, tool choice, input
handoff, working, and submission. Back reverses those steps within the same
workspace instead of opening the scheme overview. Switching tools keeps separate
completion flags; only a successful copy/download completes that handoff.

resumes them through Get started. No authored form values enter browser storage.

follow the visible form order, including saved-method selection, worker count,
time, preparation and memory. Going back preserves entries. Result-file import
goes to review only after the real import validates the exact owned instance.

the current step. A receipt still requires a confirmed server submission.
