Exactly what is being tested

Teaching Diffie–Hellman key encapsulation

Educational
The task

Given a public key and an encapsulation, recover the complete shared key. No candidate key or decapsulation oracle is supplied.

The clock

Everyone shares the same hourly round. Your answer must reach the server before the round ends. Requesting an instance later does not extend the deadline.

Construction and parameters +

In a subgroup generated by g , the public key is gˣ and the encapsulation is gʳ . Both parties derive a key from gˣʳ . The downloaded contract specifies the exact encoding and key derivation.

Shared-key output length is independent of instance size; it does not measure security strength.

Download the reference implementation ↓ · Download the teaching solver ↓

The example solver is provided for this deliberately weak teaching construction.

Correctness +

Correctness describes agreement between honest encapsulation and decapsulation. It does not establish resistance to an attack.

What a result establishes +

A correct submission establishes that the submitted key matches this instance and was received within its round. The site checks the answer and records the accompanying method and resources. It does not independently verify the declared computation or reproduce the method.

An incorrect answer locks that instance. An expired instance without an accepted recovery is simply unsolved here; it is not evidence of a security bound. Subgroup order size is a construction parameter, not an estimate of security bits.

This experiment records practical recoveries. It does not yet accept or verify asymptotic attack proofs.

Submission and ranking rules +

Each account gets one private instance per profile per round, and one well-formed answer for that instance. Submit a full 32-byte key, a reusable method version, and a compute declaration.

Method versions are immutable. Correct recoveries can appear on the public leaderboard with the account handle, method, pseudocode, and compute declaration. The earliest ten distinct accounts appear for each exact profile and version, across all rounds. Different profiles are not ranked against one another.
